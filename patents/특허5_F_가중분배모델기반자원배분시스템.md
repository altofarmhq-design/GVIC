## 【명세서】

### 【발명의 명칭】
가중 분배 모델 기반의 다영역 자원 배분 시스템 및 방법

### 【기술분야】
본 발명은 한정된 자원을 복수의 영역에 배분하는 기술에 관한 것으로, 특히 기설정된 가중 분배 모델에 따라 자원을 복수의 영역에 비율적으로 배분하고, 배분 결과를 실시간으로 모니터링 및 조정하는 시스템 및 방법에 관한 것이다.

### 【발명의 배경이 되는 기술】
현대의 조직과 시스템에서는 한정된 자원(예산, 인력, 컴퓨팅 리소스, 시간 등)을 복수의 목적 또는 영역에 효과적으로 배분해야 하는 과제가 있다. 종래의 자원 배분 방식은 대부분 임의적이거나 과거 경험에 의존하여, 최적의 배분을 달성하기 어렵다.

기존 시스템의 기술적 한계는 다음과 같다:

첫째, 자원 배분의 기준이 명확하지 않아 의사결정자의 주관에 의존한다.

둘째, 배분 비율이 고정되어 있어 상황 변화에 유연하게 대응하기 어렵다.

셋째, 배분 결과를 실시간으로 모니터링하고 조정하는 메커니즘이 부재하다.

넷째, 복수의 영역 간 자원 배분의 균형을 체계적으로 관리하지 못한다.

다섯째, 자원 배분 이력을 추적하고 분석하는 기능이 미흡하다.

따라서 수리적으로 정의된 가중 분배 모델에 따라 자원을 배분하고, 배분 결과를 실시간으로 모니터링 및 조정할 수 있는 기술이 요구된다.

### 【발명의 내용】

#### 【해결하고자 하는 과제】
본 발명은 상기한 종래 기술의 문제점을 해결하기 위하여 안출된 것으로서, 다음과 같은 기술적 과제를 해결하고자 한다.

첫째, 복수의 영역에 대한 자원 배분 비율을 수리적으로 정의하는 가중 분배 모델을 제공한다.

둘째, 가중 분배 모델에 따라 입력된 자원을 복수의 영역에 자동으로 배분하는 기술을 제공한다.

셋째, 상황 변화에 따라 배분 비율을 동적으로 조정할 수 있는 기술을 제공한다.

넷째, 각 영역의 자원 소비량과 배분 결과를 실시간으로 모니터링하는 기술을 제공한다.

다섯째, 자원 배분 이력을 기록하고 분석하여 배분 효율성을 평가하는 기술을 제공한다.

#### 【과제의 해결 수단】
상기 과제를 해결하기 위하여 본 발명에 따른 가중 분배 모델 기반의 다영역 자원 배분 시스템은 다음을 포함한다:

복수의 영역에 대한 기본 배분 비율과 조정 가능 범위를 정의하는 가중 분배 모델을 저장하는 모델 저장부(Model Repository);

외부로부터 배분 대상 자원 정보를 입력받고, 상기 가중 분배 모델에 따라 각 영역별 배분량을 산출하는 배분 연산부(Allocation Calculator);

각 영역의 실제 자원 소비량을 모니터링하고, 배분량과 소비량 간의 편차를 산출하는 소비 모니터링부(Consumption Monitor);

상기 편차가 기설정된 임계치를 초과하는 경우, 배분 비율을 동적으로 조정하는 동적 조정부(Dynamic Adjuster); 및

자원 배분 이력 및 효율성 지표를 기록하고 분석하는 분석부(Analytics Unit);를 포함한다.

본 발명의 일 실시예에 따르면, 상기 가중 분배 모델(WDM)은 다음의 구조를 갖는다:

```
WeightedDistributionModel = {
    model_id: UUID,
    domains: [
        {
            domain_id: STRING,
            domain_name: STRING,
            base_weight: FLOAT,          // 기본 배분 비율 (0-1)
            min_weight: FLOAT,           // 최소 배분 비율
            max_weight: FLOAT,           // 최대 배분 비율
            priority: INTEGER            // 조정 우선순위
        },
        ...
    ],
    constraints: {
        sum_equals_one: TRUE,            // 배분 비율 합 = 1.0
        respect_bounds: TRUE             // 경계 조건 준수
    },
    adjustment_rules: [...]              // 동적 조정 규칙
}
```

배분 연산은 다음과 같이 수행된다:

```
Total_Resource = R

For each domain i:
    Allocated[i] = R × weight[i]

Where:
    Σ weight[i] = 1.0
    min_weight[i] ≤ weight[i] ≤ max_weight[i]
```

본 발명의 핵심적 차별화 요소인 가중 분배 연산 및 동적 조정은 다음의 수학식으로 정의된다:

**[수학식 1] 가중 분배 모델 정의**
```
WDM = (D, W, B, C, A)

여기서:
- D = {d₁, d₂, ..., dₙ} : 영역(Domain) 집합
- W = {w₁, w₂, ..., wₙ} : 기본 가중치(Weight) 벡터, Σwᵢ = 1.0
- B = {(Lᵢ, Uᵢ)} : 경계(Bound) 조건 집합, Lᵢ ≤ wᵢ ≤ Uᵢ
- C : 제약 조건 집합 (합계 조건, 경계 조건 등)
- A : 조정 규칙(Adjustment Rule) 집합
```

**[수학식 2] 경계 조건 기반 배분 연산**
```
배분 함수: Alloc(R, W, B) → A

초기 배분:
Aᵢ = R × wᵢ

경계 검증 및 조정:
IF Aᵢ < R × Lᵢ THEN Aᵢ = R × Lᵢ (하한 클램핑)
IF Aᵢ > R × Uᵢ THEN Aᵢ = R × Uᵢ (상한 클램핑)

재정규화 (총합 보정):
A'ᵢ = Aᵢ × (R / Σ Aⱼ)
```

**[수학식 3] 편차 기반 동적 조정 함수**
```
편차 산출:
Δᵢ(t) = Consumedᵢ(t) - Allocatedᵢ(t)
Δ_ratio(t) = Δᵢ(t) / Allocatedᵢ(t)

동적 조정 트리거:
IF |Δ_ratioᵢ(t)| > θ_trigger THEN trigger_adjustment(i)

조정량 산출:
δwᵢ = α × sign(Δᵢ) × min(|Δ_ratioᵢ|, δ_max)

여기서:
- α : 조정 민감도 계수 (기본값 = 0.1)
- θ_trigger : 조정 트리거 임계치 (기본값 = 0.2)
- δ_max : 1회 최대 조정량 (기본값 = 0.1)
```

**[수학식 4] 우선순위 기반 재배분 알고리즘**
```
영역 우선순위: P = {p₁, p₂, ..., pₙ}, pᵢ ∈ ℕ

초과 자원 재배분:
IF Σ Aᵢ > R THEN
    excess = Σ Aᵢ - R
    FOR i in sorted_by_priority_ascending(D) DO
        reducible = Aᵢ - R × Lᵢ
        reduction = min(reducible, excess)
        Aᵢ = Aᵢ - reduction
        excess = excess - reduction
        IF excess ≤ 0 THEN BREAK
    END FOR
END IF

부족 자원 충당:
IF Σ Aᵢ < R THEN
    shortage = R - Σ Aᵢ
    FOR i in sorted_by_priority_descending(D) DO
        expandable = R × Uᵢ - Aᵢ
        expansion = min(expandable, shortage)
        Aᵢ = Aᵢ + expansion
        shortage = shortage - expansion
        IF shortage ≤ 0 THEN BREAK
    END FOR
END IF
```

**[수학식 5] 시계열 기반 예측 조정**
```
과거 소비 패턴 분석:
C_history(i, t) = [Cᵢ(t-n), Cᵢ(t-n+1), ..., Cᵢ(t-1)]

지수 이동 평균 예측:
EMA_C(i, t) = β × Cᵢ(t-1) + (1-β) × EMA_C(i, t-1)
β = 2 / (n + 1)  (n: 윈도우 크기)

예측 기반 사전 조정:
w'ᵢ(t) = wᵢ × (EMA_C(i, t) / Σⱼ EMA_C(j, t))
```

**[수학식 6] 공정성 지표 (Fairness Index)**
```
Jain's Fairness Index:
F(A) = (Σᵢ Aᵢ)² / (n × Σᵢ Aᵢ²)

범위: 1/n ≤ F ≤ 1.0
F = 1.0 : 완전 균등 배분
F = 1/n : 완전 불균등 (한 영역 독점)

가중 공정성 지표 (목표 대비):
F_weighted(A, W) = 1 - Σᵢ |Aᵢ/R - wᵢ| / 2
```

**[수학식 7] 다목적 최적화 배분**
```
목적 함수:
minimize: Z = λ₁×Deviation + λ₂×Unfairness + λ₃×Volatility

Deviation = Σᵢ (Aᵢ - Targetᵢ)²
Unfairness = 1 - F(A)
Volatility = Σᵢ |Aᵢ(t) - Aᵢ(t-1)|²

제약 조건:
Σᵢ Aᵢ = R
Lᵢ ≤ Aᵢ/R ≤ Uᵢ for all i

λ₁, λ₂, λ₃ : 목적별 가중치 (합 = 1.0)
```

**[수학식 8] 모델 전환 조건**
```
모델 집합: M = {m₁, m₂, ..., mₖ}
각 모델 mⱼ는 특정 상황 Sⱼ에 최적화

모델 선택 함수:
m*(t) = argmax_j Score(mⱼ, Context(t))

Score(mⱼ, c) = Σᵣ wᵣ × match(mⱼ.condition_r, c)

전환 조건:
IF Score(m_current, Context(t)) < Score(m_candidate, Context(t)) - θ_switch
THEN switch_model(m_candidate)
```

#### 【발명의 효과】
본 발명에 따르면 다음과 같은 효과를 얻을 수 있다.

첫째, 수리적으로 정의된 가중 분배 모델을 통해 자원 배분의 일관성과 투명성을 확보할 수 있다.

둘째, 동적 조정 기능을 통해 상황 변화에 유연하게 대응할 수 있다.

셋째, 실시간 모니터링을 통해 배분 결과와 실제 소비 간의 괴리를 신속하게 파악할 수 있다.

넷째, 경계 조건(최소/최대 비율)을 통해 특정 영역의 과도한 자원 점유 또는 자원 부족을 방지할 수 있다.

다섯째, 배분 이력 분석을 통해 배분 모델의 효율성을 지속적으로 개선할 수 있다.

#### [시스템 구성]

도 1을 참조하면, 본 발명에 따른 가중 분배 모델 기반의 다영역 자원 배분 시스템(4000)은 모델 저장부(4100), 배분 연산부(4200), 소비 모니터링부(4300), 동적 조정부(4400), 및 분석부(4500)를 포함한다.

모델 저장부(4100)는 가중 분배 모델을 저장한다. 가중 분배 모델은 복수의 영역, 각 영역의 기본 배분 비율, 최소/최대 배분 비율, 우선순위, 조정 규칙 등을 포함한다. 복수의 모델을 저장하여 상황에 따라 선택적으로 적용할 수 있다.

배분 연산부(4200)는 외부로부터 배분 대상 자원 정보를 입력받고, 선택된 가중 분배 모델에 따라 각 영역별 배분량을 산출한다. 배분 연산은 기본 배분 비율을 적용하되, 경계 조건을 준수하도록 조정한다.

소비 모니터링부(4300)는 각 영역의 실제 자원 소비량을 실시간으로 모니터링한다. 배분량과 소비량 간의 편차를 산출하고, 편차가 임계치를 초과하는 경우 알림을 생성한다.

동적 조정부(4400)는 소비 모니터링 결과에 기초하여 배분 비율을 동적으로 조정한다. 조정은 가중 분배 모델에 정의된 조정 규칙에 따라 수행되며, 경계 조건(최소/최대 비율)을 준수한다.

분석부(4500)는 자원 배분 이력, 소비 패턴, 조정 이력 등을 기록하고 분석한다. 배분 효율성 지표를 산출하고, 모델 개선을 위한 인사이트를 제공한다.

#### [핵심 알고리즘 상세]

본 발명의 차별화된 핵심 알고리즘은 다음과 같다:

**[알고리즘 1] 경계 조건 기반 배분 연산**
```
입력: 총 자원량 R, 가중 분배 모델 WDM
출력: 영역별 배분량 A = {A₁, A₂, ..., Aₙ}

1. 초기 배분:
   FOR i = 1 TO n DO
       Aᵢ = R × wᵢ
   END FOR

2. 경계 조건 검증 및 클램핑:
   FOR i = 1 TO n DO
       IF Aᵢ < R × Lᵢ THEN
           Aᵢ = R × Lᵢ  // 하한 적용
           flag_clamped[i] = LOWER
       ELSE IF Aᵢ > R × Uᵢ THEN
           Aᵢ = R × Uᵢ  // 상한 적용
           flag_clamped[i] = UPPER
       END IF
   END FOR

3. 총합 검증 및 재정규화:
   sum_A = Σᵢ Aᵢ
   IF sum_A ≠ R THEN
       // 클램핑되지 않은 영역에서 조정
       flexible_domains = {i | flag_clamped[i] == NONE}
       adjustment = (R - sum_A) / |flexible_domains|
       FOR i IN flexible_domains DO
           Aᵢ = Aᵢ + adjustment
           // 재조정 후에도 경계 검증
           Aᵢ = clamp(Aᵢ, R × Lᵢ, R × Uᵢ)
       END FOR
   END IF

4. 최종 정규화:
   IF Σᵢ Aᵢ ≠ R THEN
       // 우선순위 기반 미세 조정 수행
       call priority_based_redistribution(A, R)
   END IF

RETURN A
```

**[알고리즘 2] 실시간 편차 모니터링 및 동적 조정**
```
입력: 배분량 A, 소비량 스트림 C_stream, 조정 파라미터
출력: 조정된 가중치 W'

1. 편차 계산 (슬라이딩 윈도우):
   FOR i = 1 TO n DO
       window[i] = get_recent_consumption(i, window_size)
       avg_consumption[i] = mean(window[i])
       Δᵢ = avg_consumption[i] - Aᵢ
       Δ_ratioᵢ = Δᵢ / Aᵢ
   END FOR

2. 조정 필요성 판단:
   adjustment_needed = FALSE
   FOR i = 1 TO n DO
       IF |Δ_ratioᵢ| > θ_trigger THEN
           adjustment_needed = TRUE
           adjustment_candidates.add(i)
       END IF
   END FOR

3. 조정량 산출:
   IF adjustment_needed THEN
       // 조정 방향 및 크기 결정
       FOR i IN adjustment_candidates DO
           direction = sign(Δᵢ)
           magnitude = min(|Δ_ratioᵢ| × α, δ_max)
           δwᵢ = direction × magnitude
       END FOR
       
       // 영합 조정 (Zero-Sum Adjustment)
       positive_sum = Σ{δwᵢ | δwᵢ > 0}
       negative_sum = |Σ{δwᵢ | δwᵢ < 0}|
       
       IF positive_sum > negative_sum THEN
           scale_down_positive_adjustments()
       ELSE
           scale_down_negative_adjustments()
       END IF
       
       // 새 가중치 적용
       FOR i = 1 TO n DO
           w'ᵢ = wᵢ + δwᵢ
           w'ᵢ = clamp(w'ᵢ, Lᵢ, Uᵢ)
       END FOR
       
       // 정규화
       W' = normalize(W')
   END IF

RETURN W'
```

**[알고리즘 3] 우선순위 기반 계단식 재배분**
```
입력: 현재 배분 A, 총 자원 R, 우선순위 P
출력: 재배분된 A'

1. 초과/부족 판단:
   total_allocated = Σᵢ Aᵢ
   gap = R - total_allocated

2. 초과 시 (gap < 0) - 낮은 우선순위부터 감축:
   IF gap < 0 THEN
       excess = |gap|
       sorted_domains = sort_by_priority_ascending(D)
       
       FOR i IN sorted_domains DO
           // 해당 영역에서 감축 가능한 양
           reducible = Aᵢ - R × Lᵢ
           
           IF reducible > 0 THEN
               reduction = min(reducible, excess)
               A'ᵢ = Aᵢ - reduction
               excess = excess - reduction
               
               log_adjustment(i, "REDUCE", reduction)
               
               IF excess ≤ ε THEN BREAK
           END IF
       END FOR
   END IF

3. 부족 시 (gap > 0) - 높은 우선순위부터 증가:
   IF gap > 0 THEN
       shortage = gap
       sorted_domains = sort_by_priority_descending(D)
       
       FOR i IN sorted_domains DO
           // 해당 영역에서 증가 가능한 양
           expandable = R × Uᵢ - Aᵢ
           
           IF expandable > 0 THEN
               expansion = min(expandable, shortage)
               A'ᵢ = Aᵢ + expansion
               shortage = shortage - expansion
               
               log_adjustment(i, "EXPAND", expansion)
               
               IF shortage ≤ ε THEN BREAK
           END IF
       END FOR
   END IF

RETURN A'
```

**[알고리즘 4] 시계열 예측 기반 사전 조정**
```
입력: 소비 이력 History, 예측 윈도우 h, 모델 파라미터
출력: 예측 기반 조정된 가중치 W_predicted

1. 시계열 데이터 준비:
   FOR i = 1 TO n DO
       series[i] = extract_time_series(History, i)
   END FOR

2. 지수 이동 평균 (EMA) 예측:
   FOR i = 1 TO n DO
       β = 2 / (window_size + 1)
       EMA[i] = series[i][0]
       FOR t = 1 TO len(series[i]) DO
           EMA[i] = β × series[i][t] + (1 - β) × EMA[i]
       END FOR
       predicted_consumption[i] = EMA[i]
   END FOR

3. 추세 감지 및 반영:
   FOR i = 1 TO n DO
       trend[i] = calculate_trend(series[i])  // 선형 회귀 기울기
       IF |trend[i]| > trend_threshold THEN
           // 추세가 있으면 예측에 반영
           predicted_consumption[i] += trend[i] × h
       END IF
   END FOR

4. 예측 기반 가중치 산출:
   total_predicted = Σᵢ predicted_consumption[i]
   FOR i = 1 TO n DO
       w_predicted[i] = predicted_consumption[i] / total_predicted
       // 경계 조건 적용
       w_predicted[i] = clamp(w_predicted[i], Lᵢ, Uᵢ)
   END FOR
   
   // 정규화
   W_predicted = normalize(W_predicted)

5. 신뢰도 가중 혼합:
   confidence = calculate_prediction_confidence(series)
   FOR i = 1 TO n DO
       W_final[i] = confidence × w_predicted[i] + (1 - confidence) × wᵢ
   END FOR

RETURN W_final
```

**[알고리즘 5] 다목적 최적화 배분 (Pareto Optimal)**
```
입력: 목적 함수 가중치 λ = {λ₁, λ₂, λ₃}, 제약 조건
출력: 파레토 최적 배분 A*

1. 목적 함수 정의:
   // 목표 편차 최소화
   f₁(A) = Σᵢ (Aᵢ - Targetᵢ)²
   
   // 공정성 최대화 (불공정성 최소화)
   f₂(A) = 1 - Jain_Fairness_Index(A)
   
   // 변동성 최소화 (안정성)
   f₃(A) = Σᵢ (Aᵢ(t) - Aᵢ(t-1))²

2. 종합 목적 함수:
   Z(A) = λ₁ × f₁(A) + λ₂ × f₂(A) + λ₃ × f₃(A)

3. 제약 조건 하 최적화:
   // 그래디언트 투영법 또는 내부점 방법
   A_current = initial_allocation()
   
   WHILE NOT converged DO
       gradient = compute_gradient(Z, A_current)
       
       // 제약 조건으로 투영
       A_next = project_to_constraints(A_current - step × gradient)
       
       // 경계 조건 검증
       A_next = apply_bound_constraints(A_next, B)
       
       IF |Z(A_next) - Z(A_current)| < ε THEN
           converged = TRUE
       END IF
       
       A_current = A_next
   END WHILE

4. 파레토 최적성 검증:
   // 다른 해가 모든 목적에서 더 좋지 않은지 확인
   is_pareto_optimal = verify_pareto_optimality(A_current)

RETURN A_current
```

**[알고리즘 6] 상황 인식 모델 자동 전환**
```
입력: 모델 집합 M, 현재 컨텍스트 Context
출력: 선택된 모델 m*, 전환 여부

1. 컨텍스트 특징 추출:
   features = {
       time_of_day: get_hour(),
       day_of_week: get_weekday(),
       load_level: get_current_load(),
       trend: get_recent_trend(),
       anomaly_score: get_anomaly_score()
   }

2. 각 모델 적합도 평가:
   FOR each model m IN M DO
       score[m] = 0
       FOR each condition c IN m.conditions DO
           match_score = evaluate_condition(c, features)
           score[m] += c.weight × match_score
       END FOR
   END FOR

3. 최적 모델 선택:
   m_best = argmax(score)
   m_current = get_current_model()

4. 전환 결정:
   IF m_best ≠ m_current THEN
       score_diff = score[m_best] - score[m_current]
       IF score_diff > θ_switch THEN
           // 히스테리시스 적용 (잦은 전환 방지)
           IF time_since_last_switch() > min_switch_interval THEN
               switch_model(m_best)
               log_model_switch(m_current, m_best, score_diff)
               RETURN m_best, TRUE
           END IF
       END IF
   END IF

RETURN m_current, FALSE
```

#### [실시예 1: 기업 예산 배분]

### 【도 6】 우선순위 기반 재배분 알고리즘

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      우선순위 기반 계단식 재배분                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   입력: 현재 배분 A, 총 자원 R, 우선순위 P                                   │
│                                                                             │
│        ┌─────────────────┐                                                  │
│        │ 총합 검증       │                                                  │
│        │ gap = R - ΣAᵢ   │                                                  │
│        └────────┬────────┘                                                  │
│                 │                                                           │
│         ┌───────┴───────┐                                                   │
│         │               │                                                   │
│    [gap < 0]       [gap > 0]                                                │
│    (초과)           (부족)                                                   │
│         │               │                                                   │
│         ▼               ▼                                                   │
│  ┌─────────────┐  ┌─────────────┐                                          │
│  │ 우선순위    │  │ 우선순위    │                                          │
│  │ 낮은 순서   │  │ 높은 순서   │                                          │
│  │ 정렬       │  │ 정렬        │                                          │
│  └──────┬──────┘  └──────┬──────┘                                          │
│         │               │                                                   │
│         ▼               ▼                                                   │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    계단식 조정 루프                                  │   │
│  │                                                                     │   │
│  │   FOR each 영역 i (정렬 순서대로):                                   │   │
│  │       조정가능량 = |Aᵢ - 경계값|                                     │   │
│  │       실제조정량 = min(조정가능량, 잔여gap)                          │   │
│  │       Aᵢ = Aᵢ ± 실제조정량                                          │   │

│  │       IF 잔여gap ≤ 0 THEN BREAK                                     │   │
│  │   END FOR                                                           │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │

│   부족 시: 응급(1) → 수술(2) → 입원(3) 순으로 증가                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
