## 【명세서】

### 【발명의 명칭】
비적합 데이터 자산화 시스템 및 방법

### 【기술분야】
본 발명은 데이터 처리 과정에서 발생하는 비적합 데이터(Non-Conforming Data)의 처리 기술에 관한 것으로, 특히 기존 처리 규칙에 부합하지 않아 폐기되던 데이터를 별도로 분류, 분석하여 2차 가치를 갖는 자산으로 변환하는 시스템 및 방법에 관한 것이다.

### 【발명의 배경이 되는 기술】
종래의 데이터 처리 시스템은 입력 데이터가 기설정된 처리 규칙 또는 스키마에 부합하지 않는 경우, 해당 데이터를 단순히 오류로 처리하거나 폐기하였다. 그러나 이러한 비적합 데이터에는 다음과 같은 잠재적 가치가 포함될 수 있다:

- 새로운 데이터 패턴의 출현을 나타내는 신호
- 기존 처리 규칙의 한계를 드러내는 피드백
- 예외적이지만 중요한 비즈니스 이벤트
- 시스템 또는 프로세스의 개선점을 시사하는 정보

기존 시스템의 기술적 한계는 다음과 같다:

첫째, 비적합 데이터를 일률적으로 폐기함으로써 잠재적으로 유용한 정보가 소실된다.

둘째, 비적합 데이터의 발생 원인과 패턴을 체계적으로 분석하는 메커니즘이 부재하다.

셋째, 비적합 데이터를 재처리하거나 활용하기 위한 별도의 워크플로우가 존재하지 않는다.

넷째, 비적합 데이터의 축적으로 인한 저장 비용 증가와 관리 복잡성 문제가 발생한다.

따라서 비적합 데이터를 체계적으로 분류하고, 그 가치를 평가하여 2차 자산으로 변환하는 기술이 요구된다.

### 【발명의 내용】

#### 【해결하고자 하는 과제】
본 발명은 상기한 종래 기술의 문제점을 해결하기 위하여 안출된 것으로서, 다음과 같은 기술적 과제를 해결하고자 한다.

첫째, 데이터 처리 과정에서 발생하는 비적합 데이터를 단순 폐기하지 않고 별도로 격리 및 저장하는 기술을 제공한다.

둘째, 격리된 비적합 데이터를 비적합 유형별로 분류하고, 각 유형의 특성을 분석하는 기술을 제공한다.

셋째, 비적합 데이터의 잠재적 가치를 평가하고, 가치가 인정되는 데이터를 2차 자산으로 변환하는 기술을 제공한다.

넷째, 비적합 데이터의 발생 패턴을 분석하여 기존 처리 규칙의 개선점을 도출하는 기술을 제공한다.

다섯째, 비적합 데이터의 처리 이력과 변환 결과를 투명하게 기록하는 기술을 제공한다.

#### 【과제의 해결 수단】
상기 과제를 해결하기 위하여 본 발명에 따른 비적합 데이터 자산화 시스템은 다음을 포함한다:

데이터 처리 파이프라인에서 기존 처리 규칙에 부합하지 않는 비적합 데이터를 감지하고, 이를 별도의 격리 저장소로 라우팅하는 비적합 감지부(Non-Conformance Detector);

상기 격리 저장소에 저장된 비적합 데이터를 비적합 유형(스키마 불일치, 값 범위 위반, 형식 오류, 논리적 모순 등)별로 분류하는 비적합 분류부(Non-Conformance Classifier);

분류된 비적합 데이터에 대하여 가치 평가 알고리즘을 적용하여 잠재적 가치 점수를 산출하는 가치 평가부(Value Assessor);

기설정된 가치 임계치 이상의 비적합 데이터를 2차 자산 객체로 변환하는 자산 변환부(Asset Converter); 및

비적합 데이터의 발생 패턴을 분석하여 기존 처리 규칙의 개선점을 도출하는 규칙 개선 제안부(Rule Improvement Suggester);를 포함한다.

본 발명의 일 실시예에 따르면, 상기 비적합 데이터의 가치 평가는 다음의 요소를 고려한다:

```
ValueScore = f(
    Frequency,          // 발생 빈도
    Recency,           // 최근성
    PatternNovelty,    // 패턴 신규성
    BusinessRelevance, // 비즈니스 관련성
    RecoveryCost       // 복구 비용
)
```

여기서 높은 빈도, 높은 최근성, 높은 패턴 신규성, 높은 비즈니스 관련성, 낮은 복구 비용을 갖는 비적합 데이터가 높은 가치 점수를 갖는다.

#### 【발명의 효과】
본 발명에 따르면 다음과 같은 효과를 얻을 수 있다.

첫째, 종래에 폐기되던 비적합 데이터로부터 2차 가치를 추출하여 자원 활용도를 극대화할 수 있다.

둘째, 비적합 데이터의 체계적 분류를 통해 데이터 품질 이슈의 근본 원인을 파악할 수 있다.

셋째, 가치 평가 메커니즘을 통해 한정된 리소스를 가치 있는 비적합 데이터의 처리에 집중할 수 있다.

넷째, 규칙 개선 제안을 통해 기존 처리 규칙을 지속적으로 개선하여 미래의 비적합 발생을 감소시킬 수 있다.

다섯째, 비적합 데이터의 처리 이력을 투명하게 기록함으로써 감사 및 컴플라이언스 요구를 충족할 수 있다.

### 【도면의 간단한 설명】
**【도 1】** 본 발명에 따른 비적합 데이터 자산화 시스템의 전체 구성을 나타내는 블록도이다.

**【도 2】** 비적합 데이터의 감지 및 라우팅 프로세스를 나타내는 도면이다.

**【도 3】** 비적합 유형 분류 체계를 나타내는 도면이다.

**【도 4】** 가치 평가 알고리즘의 처리 흐름을 나타내는 플로우차트이다.

**【도 5】** 2차 자산 객체의 구조를 나타내는 도면이다.

**【도 6】** 규칙 개선 제안 프로세스를 나타내는 도면이다.

### 【발명을 실시하기 위한 구체적인 내용】

이하, 첨부된 도면을 참조하여 본 발명의 바람직한 실시예를 상세히 설명한다.

#### [시스템 구성]

도 1을 참조하면, 본 발명에 따른 비적합 데이터 자산화 시스템(3000)은 비적합 감지부(3100), 격리 저장소(3150), 비적합 분류부(3200), 가치 평가부(3300), 자산 변환부(3400), 및 규칙 개선 제안부(3500)를 포함한다.

비적합 감지부(3100)는 데이터 처리 파이프라인의 각 단계에서 비적합 데이터를 실시간으로 감지한다. 비적합의 기준은 스키마 불일치, 값 범위 위반, 형식 오류, 논리적 모순, 무결성 제약 위반 등 다양한 조건을 포함한다. 감지된 비적합 데이터는 격리 저장소(3150)로 라우팅된다.

격리 저장소(3150)는 비적합 데이터를 별도로 저장하며, 원본 데이터, 비적합 사유, 감지 시점, 원천 정보 등의 메타데이터를 함께 기록한다.

비적합 분류부(3200)는 격리된 비적합 데이터를 유형별로 분류한다. 분류 기준은 다음을 포함한다:
- 구조적 비적합: 스키마 불일치, 필수 필드 누락
- 값 비적합: 범위 위반, 형식 오류, 타입 불일치
- 논리적 비적합: 비즈니스 규칙 위반, 모순 관계
- 시간적 비적합: 순서 위반, 타임스탬프 이상

가치 평가부(3300)는 분류된 비적합 데이터에 대하여 가치 평가 알고리즘을 적용한다. 가치 평가 알고리즘은 발생 빈도, 최근성, 패턴 신규성, 비즈니스 관련성, 복구 비용 등을 종합적으로 고려하여 가치 점수를 산출한다.

자산 변환부(3400)는 기설정된 가치 임계치 이상의 비적합 데이터를 2차 자산 객체로 변환한다. 2차 자산 객체는 원본 비적합 데이터, 분류 정보, 가치 평가 결과, 제안된 활용 방안 등을 포함한다.

규칙 개선 제안부(3500)는 비적합 데이터의 발생 패턴을 분석하여 기존 처리 규칙의 개선점을 도출한다. 예를 들어, 특정 유형의 비적합이 빈번하게 발생하면, 해당 유형을 처리할 수 있도록 규칙 확장을 제안한다.

#### [실시예 1: 이커머스 고객 데이터 처리]

본 실시예에서 비적합 데이터 자산화 시스템은 이커머스 플랫폼의 고객 데이터 처리에 적용된다.

기존 처리 규칙은 다음과 같다:
- 이메일 형식: 표준 이메일 형식
- 전화번호 형식: 국가별 표준 형식
- 주소: 우편번호 유효성 검증
- 구매 금액: 양수 값

비적합 데이터의 예시와 2차 자산화:

1. **형식 비적합 (이메일)**
   - 비적합 사례: "customer(at)email.com"
   - 발생 빈도: 높음 (일 1,000건 이상)
   - 가치 평가: 높음 (자동 변환 가능, 고객 연락처 확보)
   - 2차 자산: 형식 자동 변환 후 유효 고객 데이터로 편입

2. **값 비적합 (구매 금액 음수)**
   - 비적합 사례: 구매 금액 = -50,000
   - 발생 빈도: 낮음 (일 10건 미만)
   - 가치 평가: 높음 (환불/취소 누락 가능성)
   - 2차 자산: 환불 처리 검토 대상 리스트

3. **논리적 비적합 (미래 날짜 주문)**
   - 비적합 사례: 주문일 = 2025-12-31 (현재: 2024-06)
   - 발생 빈도: 매우 낮음
   - 가치 평가: 중간 (시스템 오류 또는 테스트 데이터)
   - 2차 자산: 시스템 점검 트리거 이벤트

규칙 개선 제안:
- 이메일 형식 규칙에 자동 변환 로직 추가 제안
- 구매 금액 규칙에 환불/취소 별도 처리 경로 추가 제안

#### [실시예 2: IoT 센서 데이터 처리]

본 실시예에서 비적합 데이터 자산화 시스템은 IoT 센서 데이터 처리에 적용된다.

기존 처리 규칙은 다음과 같다:
- 온도 범위: -40°C ~ 150°C
- 습도 범위: 0% ~ 100%
- 타임스탬프: 현재 시간 ± 5분 이내

비적합 데이터의 예시와 2차 자산화:

1. **값 비적합 (온도 범위 초과)**
   - 비적합 사례: 온도 = 200°C
   - 발생 빈도: 센서 A에서 집중 발생
   - 가치 평가: 매우 높음 (센서 고장 또는 실제 이상 상황)
   - 2차 자산: 긴급 점검 대상 설비 리스트

2. **시간적 비적합 (순서 위반)**
   - 비적합 사례: 타임스탬프 역전
   - 발생 빈도: 특정 게이트웨이에서 발생
   - 가치 평가: 중간 (네트워크 지연 또는 동기화 이슈)
   - 2차 자산: 네트워크 인프라 점검 트리거

3. **구조적 비적합 (필드 누락)**
   - 비적합 사례: 센서 ID 필드 누락
   - 발생 빈도: 펌웨어 업데이트 후 발생
   - 가치 평가: 높음 (펌웨어 버그 가능성)
   - 2차 자산: 펌웨어 롤백 검토 대상

규칙 개선 제안:
- 센서별 동적 범위 설정 기능 추가 제안
- 타임스탬프 동기화 허용 범위 조정 제안

#### [입출력 어댑터에 관한 사항]

본 발명의 입력 데이터 형태 및 비적합 기준은 운영 환경에 따라 다양하게 구성될 수 있으며, 이는 본 발명의 핵심 기술적 특징인 "비적합 감지 → 분류 → 가치 평가 → 자산 변환"의 프로세스를 벗어나지 않는 범위에서 운영상 결정되는 사항이다.

### 【산업상 이용가능성】
본 발명은 데이터 품질 관리가 중요한 이커머스, 금융, 제조, 헬스케어, IoT 등 다양한 산업 분야에 적용 가능하다. 특히 대량의 데이터를 처리하면서 비적합 데이터의 발생이 불가피한 환경에서 유용하다.

## 【청구범위】

### 【청구항 1】 (독립항 - 시스템)
데이터 처리 파이프라인에서 기존 처리 규칙에 부합하지 않는 비적합 데이터를 감지하고, 이를 별도의 격리 저장소로 라우팅하는 비적합 감지부;

상기 격리 저장소에 저장된 비적합 데이터를 비적합 유형별로 분류하는 비적합 분류부;

분류된 비적합 데이터에 대하여 가치 평가 알고리즘을 적용하여 잠재적 가치 점수를 산출하는 가치 평가부; 및

기설정된 가치 임계치 이상의 비적합 데이터를 2차 자산 객체로 변환하는 자산 변환부;

를 포함하는 비적합 데이터 자산화 시스템.

### 【청구항 2】 (독립항 - 방법)
비적합 데이터 자산화 방법에 있어서,

(a) 비적합 감지부가 데이터 처리 파이프라인에서 기존 처리 규칙에 부합하지 않는 비적합 데이터를 감지하는 단계;

(b) 상기 비적합 데이터를 격리 저장소에 저장하는 단계;

(c) 비적합 분류부가 상기 비적합 데이터를 유형별로 분류하는 단계;

(d) 가치 평가부가 상기 분류된 비적합 데이터에 대하여 가치 평가를 수행하여 가치 점수를 산출하는 단계; 및

(e) 자산 변환부가 상기 가치 점수가 기설정된 임계치 이상인 비적합 데이터를 2차 자산 객체로 변환하는 단계;

를 포함하는 비적합 데이터 자산화 방법.

### 【청구항 3】 (독립항 - 가치 평가 장치)
비적합 데이터의 가치를 평가하는 장치에 있어서,

비적합 데이터의 발생 빈도를 측정하는 빈도 분석부;
비적합 데이터의 최근성을 측정하는 시간 분석부;
비적합 데이터의 패턴 신규성을 측정하는 패턴 분석부;
비적합 데이터의 비즈니스 관련성을 측정하는 관련성 분석부; 및
상기 측정 결과를 종합하여 가치 점수를 산출하는 점수 산출부;

를 포함하는 비적합 데이터 가치 평가 장치.

### 【청구항 4】 (종속항)
제1항에 있어서,

상기 시스템은 비적합 데이터의 발생 패턴을 분석하여 기존 처리 규칙의 개선점을 도출하는 규칙 개선 제안부를 더 포함하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 5】 (종속항)
제1항에 있어서,

상기 비적합 유형은 구조적 비적합, 값 비적합, 논리적 비적합, 시간적 비적합 중 적어도 하나를 포함하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 6】 (종속항)
제1항에 있어서,

상기 격리 저장소는 원본 비적합 데이터, 비적합 사유, 감지 시점, 원천 정보를 포함하는 메타데이터를 함께 저장하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 7】 (종속항)
제2항에 있어서,

상기 (d) 단계의 가치 평가는 발생 빈도, 최근성, 패턴 신규성, 비즈니스 관련성, 복구 비용 중 적어도 둘 이상을 고려하는 것을 특징으로 하는 비적합 데이터 자산화 방법.

### 【청구항 8】 (종속항)
제2항에 있어서,

상기 (e) 단계의 2차 자산 객체는 원본 비적합 데이터, 분류 정보, 가치 평가 결과, 제안된 활용 방안을 포함하는 것을 특징으로 하는 비적합 데이터 자산화 방법.

### 【청구항 9】 (종속항)
제1항에 있어서,

상기 비적합 감지부는 복수의 감지 규칙을 적용하고, 각 규칙에 의해 감지된 비적합 사항을 개별적으로 기록하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 10】 (종속항)
제1항에 있어서,

상기 자산 변환부는 변환된 2차 자산 객체를 외부 시스템으로 송출하는 인터페이스를 포함하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 11】 (종속항)
제3항에 있어서,

상기 패턴 분석부는 기존에 관찰되지 않은 새로운 비적합 패턴을 감지하고, 해당 패턴에 높은 신규성 점수를 부여하는 것을 특징으로 하는 비적합 데이터 가치 평가 장치.

### 【청구항 12】 (종속항)
제2항에 있어서,

상기 방법은 가치 임계치 미만의 비적합 데이터를 기설정된 보존 기간 동안 격리 저장소에 유지한 후 자동 삭제하는 단계를 더 포함하는 것을 특징으로 하는 비적합 데이터 자산화 방법.

### 【청구항 13】 (종속항)
제1항에 있어서,

상기 시스템은 비적합 데이터의 처리 이력을 불변 기록으로 저장하는 감사 로그부를 더 포함하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

### 【청구항 14】 (종속항)
제2항에 있어서,

상기 방법은 규칙 개선 제안부가 비적합 발생 패턴에 기초하여 처리 규칙 확장을 제안하는 단계를 더 포함하는 것을 특징으로 하는 비적합 데이터 자산화 방법.

### 【청구항 15】 (종속항)
제1항에 있어서,

상기 가치 평가부는 비적합 데이터의 가치 점수를 주기적으로 재평가하고, 시간 경과에 따른 가치 변화를 추적하는 것을 특징으로 하는 비적합 데이터 자산화 시스템.

## 【요약서】

### 【요약】
본 발명은 데이터 처리 과정에서 발생하는 비적합 데이터를 자산화하는 시스템 및 방법에 관한 것으로, 기존 처리 규칙에 부합하지 않아 폐기되던 데이터를 2차 가치를 갖는 자산으로 변환하는 기술을 제공한다. 본 발명에 따르면, 비적합 감지부가 비적합 데이터를 격리하고, 비적합 분류부가 유형별로 분류하며, 가치 평가부가 발생 빈도, 최근성, 패턴 신규성, 비즈니스 관련성 등을 고려하여 가치를 평가하고, 자산 변환부가 가치 있는 데이터를 2차 자산 객체로 변환한다. 이를 통해 폐기되던 데이터로부터 가치를 추출하고 처리 규칙을 지속적으로 개선할 수 있다.
