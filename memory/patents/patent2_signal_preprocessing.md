# 특허 2: 재귀적 모듈화를 이용한 다단계 신호 전처리 시스템

## 기본 정보
- **영문명**: Multi-stage Signal Preprocessing System and Method Using Recursive Modularization
- **기술분야**: 신호 데이터의 수집, 분류 및 정제

## 시스템 구성요소

| 구성요소 | 부호 | 설명 |
|---------|------|------|
| 벡터 변환부 | 310 | 신호 데이터를 n차원 특성 벡터로 변환 |
| 정합성 판별부 | 320 | 기준 벡터(Σ)와 코사인 유사도로 정합성 판별 |
| 재모듈화 처리부 | 330 | 비정합 신호를 재귀적으로 분해/재분류 |
| 정제 처리부 | 340 | 정합 신호에서 핵심 성분 추출 (PCA/ICA) |
| 모듈 생성부 | 350 | 특성별 모듈로 구조화 및 태그 부여 |
| 적응형 분류 장치 | 360 | 미분류 패턴 학습 및 규칙 업데이트 |

## 핵심 수학식

### 정합성 지수 (Conformance Index)
```
S_idx = (V · Σ) / (|V| × |Σ|)

여기서:
- V: 입력 신호의 특성 벡터
- Σ: 시스템 기준 벡터
- 결과: 코사인 유사도 (-1 ~ 1)

판별:
- S_idx ≥ τ (임계치) → 정합 신호 → 정제 처리
- S_idx < τ → 비정합 신호 → 재귀적 재분류
```

### 재귀적 재분류 알고리즘
```
Module_k = Classify(N, k)  for k = 1, 2, ..., K

if ∃ n ∈ N : Unclassified(n)
    then N' = {n | Unclassified(n)}
    Recurse(N', k+1)

종료 조건:
- 최대 반복 횟수 도달
- 더 이상 분해 불가능
- 최종 미분류 → 미분류 모듈로 저장
```

## 처리 흐름

### 1. 벡터 변환
- 텍스트: NLP 기반 임베딩
- 센서: FFT(푸리에 변환)
- 이미지: CNN 특징 추출

### 2. 정합성 판별
```
IF S_idx >= τ THEN
    → 정합 신호 → 정제 처리부로 전달
ELSE
    → 비정합 신호 → 재모듈화 처리부로 전달
```

### 3. 재귀적 재모듈화
```
1. 비정합 신호를 하위 신호로 분해
2. 각 하위 신호에 대해 정합성 재판별
3. 정합: 모듈 생성
4. 비정합: 분해 가능 여부 확인
   - 가능: 재귀 호출
   - 불가능: 미분류 모듈 저장
```

### 4. 정제 처리
- PCA (주성분 분석)
- ICA (독립 성분 분석)
- 노이즈 제거, 핵심 키워드 추출

### 5. 모듈 생성
- 특성별 그룹화
- 태그 부여 (감성, 주제, 영역 등)

## 적용 예시

### 이커머스 피드백 처리
```
입력: "이 원피스 디자인은 정말 예쁜데 사이즈가 너무 작아요..."

1단계 - 정합성 판별:
- 복합 감성으로 S_idx = 0.65 < τ(0.7) → 비정합

2단계 - 재귀적 재분류:
- "디자인은 예쁜데" → S_idx=0.85 → 정합/긍정/디자인
- "사이즈가 작아요" → S_idx=0.82 → 정합/부정/품질
- "배송도 느리고" → S_idx=0.80 → 정합/부정/물류

결과: 1개 비정합 → 3개 정합 모듈로 분리
```

### 스마트 팩토리 설비 관리
```
입력: 진동+35%, 온도 정상, 전류+8%, "이상한 소리"

분석:
- 진동↑ + 전류↑ + 이상소리 = 베어링 마모 패턴 87% 유사
- 예측 잔여 수명: 21일

출력: 예지정비 모듈 생성
```
