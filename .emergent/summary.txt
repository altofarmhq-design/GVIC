<analysis>**original_problem_statement:**
The user wants to build a sophisticated AI-powered platform named GVIC. The core philosophy is to treat the *intent* behind any input signal (text, file, URL) as a tradable asset.

The system's lifecycle follows a 5-stage pipeline:
1.  **Input (입력단)**: A signal enters the system.
2.  **Evaluation (시그널 평가단)**: The signal is classified into wanted (for direct analysis), unwanted (for assetization), and null based on a user-adjustable ratio.
3.  **Core (코어부분)**: Wanted signals are processed by an AI analyzer to provide a direct answer.
4.  **Assetization (자산화)**: A single input signal can be broken down into multiple distinct assets based on its features. These assets are analyzed for hidden value, scored, and stored.
5.  **Monetization (모듈화/판매/보상)**: Assets with similar characteristics are bundled into modules. When a module is purchased, 20% of the sale price is distributed as points among the original contributors of the assets within that module.

A user point system is integrated, allowing users to earn points for their contributions. These points can later be used for platform services. The exchange rate is currently set to 1000 Points = ₩1.
