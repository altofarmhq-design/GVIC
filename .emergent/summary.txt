<analysis>**original_problem_statement:**
The user wants to build a sophisticated AI-powered platform named GVIC. The core philosophy is to treat the *intent* behind any input signal as a tradable asset.

The system's lifecycle follows a 5-stage pipeline:
1.  **Input (입력단)**: A signal (text, file, URL, etc.) enters the system.
2.  **Evaluation (시그널 평가단)**: The signal is classified into wanted (for direct analysis), unwanted (for assetization), and null. This classification is guided by a user-adjustable 5:3:2 ratio.
3.  **Core (코어부분)**: Wanted signals are processed by an AI analyzer to provide a direct answer to the user. The analysis can be of three types: General, Code Analysis, or Patent/Idea Analysis.
4.  **Assetization (자산화)**: Unwanted and null signals are analyzed for hidden value, scored, and stored as assets in a database.
5.  **Monetization (모듈화/판매/보상)**: Assets are packaged into modules, priced, and made available for sale, with a system to calculate rewards for the original contributors.

Two key user roles exist: the **Requester** (who inputs a query and gets a direct answer) and the **Planner/Operator** (who monitors the internal pipeline stages via a dashboard).
